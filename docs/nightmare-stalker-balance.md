# Кошмарный сталкер: баланс для сервера без сна

Проверено по установленному `born_in_chaos_[Neoforge]_1.21.1_1.7.6.jar`
(SHA-256 `a0271a24db8622434d9573c5e789d451a05c9211173885049284e1911e2499c7`).

## Причина

В `NightmareStalkerNaturalnoieUsloviiePoiavlieniiaSushchnostiProcedure` спавн
проверяет **возраст мира** от 61000 тиков, темноту, биом, измерение и gamerule
`theappearanceoftheNightmareStalker`. Статистика сна игрока не проверяется.
На сервере при проверке было 9117 игровых дней, сложность Hard.

Базовые характеристики: 70 HP, урон 7, скорость 0.28, обнаружение 80 блоков,
броня 4. С 50 дней появляются Strength II / Resistance I, со 100 — III / III.
На Hard один обычный удар при Strength III — 24 урона до защиты игрока.
Наш случайный профиль xlentity дополнительно увеличивал базовые атрибуты:
HP в 1.28–2.5 раза, иногда урон/скорость; шанс Regeneration II — 50%.
Это превращало рядового ночного противника в непредсказуемого мини-босса.

При попадании по игроку без эффекта Gaze of Terror мод даёт Wither II на 10 секунд
и лечит сталкера Regeneration V 4 секунды. Попадания по мобам дополнительно
накапливают Strength. После семи ударов по раненому сталкеру возможна фаза
Terrifying Presence длительностью 100 секунд: Resistance III, самолечение,
аура 4 урона Wither раз в 31 тик в кубе с полустороной 7 блоков.

## Новый профиль (xlentity 1.0.4)

| Параметр | Значение |
|---|---|
| Базовое здоровье | 60 HP / 30 сердец |
| Базовый урон | 6; на Hard обычный удар 9 до защиты |
| Скорость | 0.25 |
| Обнаружение | 32 блока |
| Случайные усиления xlentity | Для сталкера отключены, включая экипировку и зелья |
| Усиление за возраст мира | Боевые процедуры видят не более 49 дней |
| Strength от атак по животным | Заблокирован только у сталкера |
| Лечение после попадания | Regeneration I, максимум 3 секунды |
| Wither после попадания по игроку | I, 10 секунд (ранняя штатная стадия) |
| Ярость | До 6 секунд за активацию; исходные условия повторной активации сохранены |
| Защита в ярости | Resistance I, 20% вместо 60% |
| Аура ярости | 2 вместо 4 урона за импульс; штатный радиус сохранён |

Невидимость при полном здоровье, иммунитет к стрелам и отдельным типам урона,
ночной спавн, исчезновение на солнце, анимации и лут не меняются.
Реальное время мира, сон и остальные мобы не изменяются.
Здоровье уже раненых сталкеров при загрузке чанка не увеличивается.
Существующая экипировка/модификаторы сторонних модов не удаляются.

## Настройка и активация

В `config/xlentity.json` добавлен раздел:

```json
"nightmareStalker": {
  "enabled": true,
  "maxHealth": 60.0,
  "attackDamage": 6.0,
  "movementSpeed": 0.25,
  "followRange": 32.0
}
```

Без раздела используются эти же значения. Некорректные численные значения
атрибутов заменяются безопасными значениями по умолчанию.
После установки jar нужен **перезапуск, который пользователь выполняет сам**.
Обычный `/xlentity reload` или `systemctl reload` не заменяет загруженные классы Java.
В дальнейшем `/xlentity reload` перечитывает параметры: боевые ограничения
меняются сразу, атрибуты — при следующем спавне/загрузке сущности.
`enabled: false` отключает боевые перехваты и профиль новых мобов; уже записанные
атрибуты существующих мобов автоматически к исходным не возвращаются.

## Проверка

`gradlew build stalkerTestJar --offline` собирает релиз и отдельный тестовый jar.
Тестовый jar **не деплоить**. Он запускается только с `-Dxlentity.stalkerTest=true`,
на loopback-сервере без игроков и с миром `stalker-test-world-20261004`.
Проверяет реальные преобразованные классы Born in Chaos через NeoForge/Arclight:
характеристики, повторную загрузку раненого моба, отсутствие возрастных усилений,
лечение, Wither, длительность ярости и её защиту, неизменность времени мира,
контрольную ванильную сущность и возврат штатных эффектов при отключении профиля.
Фикстура сама останавливает только свой локальный процесс после проверки.

Mixin `@Pseudo` допускает отсутствие Born in Chaos. Если мод установлен, точки
внедрения обязательны: при обновлении его версии повторить нативную проверку.
